# Assignment 3: Discrete Event CPU Simulation

This program runs a process scheduling simulation of 1000 processes using five core scheduling algorithms:
- First Come First Serve (FCFS)
- Shortest Job First (SJF)
- Shortest Remaining Time First (SRTF)
- Round Robin (RR), with a quantum time of q=2.0
- Highest Response Ratio First (HRRN)

The program runs each of the algorithms and outputs their metrics in a markdown table.

## Compilation
To compile the program, do the following
- For a Linux environment, execute the ./run.sh file with this directory as the working directory
- For a Windows environment, execute the ./run.bat file with this directory as the working directory
